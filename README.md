# Flex-Web

Site vitrine de Flex-Web, marque commerciale de Fleximmo, pour la création de sites internet et d'applications mobiles en Savoie et Haute-Savoie.

## Stack

- Astro 6
- React 19
- Tailwind CSS 4
- Framer Motion

## Développement

```bash
npm install
npm run dev
npm run build
```

## Automatisation commerciale

Le parcours projet, Stripe, Brevo et le tableau de bord sont décrits dans [docs/AUTOMATISATION.md](docs/AUTOMATISATION.md). Le code est disponible ; le raccordement de la base et des services en ligne reste nécessaire avant activation publique.
